# AsgardOS distribution tree

The build tree of AsgardOS, a Linux gaming OS for the AYN Thor. See the repository's top-level README for
what AsgardOS is, how to build it and how to install a build.

AsgardOS is a fork of [ROCKNIX](https://github.com/ROCKNIX/distribution) (forked 2026-10-30 at `7cffc96`),
which is itself a fork of [JELOS](https://github.com/JustEnoughLinuxOS/distribution/). ROCKNIX's history up to the
fork is kept in this repository. Licenses: [LICENSE.md](LICENSE.md) and each component's own license; original
ROCKNIX and JELOS code keeps its copyright notices.
